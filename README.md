# 自動車メンテナンス履歴

自動車のメンテナンス履歴と費用を記録するブラウザアプリです。インストール不要で、`index.html` をブラウザで開くだけで使えます（インターネット接続も不要）。

## 機能

- **車両基本情報（上段）** … 車名・メーカー・型式・初度登録年月・登録番号・車台番号・原動機の型式・購入日・購入時走行距離・車検満了日・メモ
- **メンテナンス履歴（1件＝横1行）** … 日付・走行距離・メンテナンス内容・使用部品・部品代・工賃（合計は自動計算）・備考
  - 先頭の入力行に入力して「追加」（または Enter）で登録
  - 登録済みの行はセルを直接編集できます
  - メンテナンス内容は、過去の入力や定番項目から**リストで選択**できます。リストにないものは「✎ 手入力…」で入力します（同じ名前で揃えると間隔分析が正確になります）
  - 使用部品も**リストで選択**できます。選んだメンテナンス内容で過去に使った部品（新しく使った順）が出るので、例えば「エンジンオイル交換」を選ぶと過去のオイルの種類が並びます。こちらも「✎ 手入力…」で新しい部品を入力できます
- **並び替え・絞り込み** … 見出しクリックまたは「並び替え」で、メンテナンス内容・日付・走行距離・金額などで並び替え。メンテナンス内容で絞り込みも可能
- **同じ内容のメンテナンス間隔** … 内容を選ぶと、各回の「前回からの期間（○年○ヶ月○日・日数）」「前回からの走行距離」、平均・最短・最長を表示。内容別サマリーでは前回実施からの経過期間・距離も確認できます
- **Excel 出力** … 「Excel出力」で `.xlsx` を保存。シート構成：
  1. メンテナンス履歴（車両情報＋画面に表示中の一覧と合計）
  2. 間隔分析（内容ごとの前回からの期間・距離）
  3. 内容別サマリー
- **車体の写真** … 車両ごとに1枚登録できます（長辺 960px に縮小して保存。バックアップにも含まれます）
- **複数車両** … ヘッダーで車両を追加・切り替えできます
- **バックアップ** … データは使用中のブラウザ（localStorage）に保存されます。JSON でバックアップ／復元できます

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | スタイル |
| `js/app.js` | 画面操作・保存・Excel 出力 |
| `js/analysis.js` | 合計・並び替え・間隔計算などのロジック |
| `vendor/xlsx.full.min.js` | Excel 出力ライブラリ [SheetJS](https://sheetjs.com/) 0.18.5（Apache-2.0） |
| `test.js` | ロジックのテスト（`node test.js`） |
